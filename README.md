# NEON DRIFT — мультиплеєрна .io-арена

Ти — неонова клітина на арені 4000×4000. Збирай енергетичні кулі, щоб рости, поглинай гравців, менших за тебе (потрібно бути більшим на 20 %+), і тримайся подалі від червоних мін: вони вибухають і забирають 40 % маси у великих гравців (а малі можуть ховатися за ними).

## Запуск
```bash
npm install
npm start
```
Відкрий http://localhost:3000 у двох вкладках (або з телефона в тій самій Wi-Fi мережі за LAN-адресою, яку сервер пише в консоль).

## Керування
- **Миша** — напрямок руху (що далі курсор, то швидше)
- **Пробіл / ЛКМ / ПКМ** — прискорення (коштує маси, залишає за тобою слід)
- **Телефон** — веди пальцем, кнопка ⚡ для прискорення
- **Enter** на екрані програшу — миттєвий перезапуск з тим самим ніком

## Технічно
- `server.js` — авторитетний сервер Node.js + Socket.io: фізика 60 Гц, розсилка стану 20 Гц, лідерборд 2 Гц, AI-боти (`BOTS=0 npm start`, щоб вимкнути).
- `public/` — клієнт на Canvas 2D з інтерполяцією позицій, частинками, мінікартою й адаптивним HUD.
- Нікнейм і колір зберігаються в localStorage.
